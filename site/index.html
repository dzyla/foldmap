Protein topology diagrams, drawn from the structure.

foldmap turns a PDB/mmCIF file, a PDB ID or an AlphaFold model into a clean 2D map of its helices, strands and loops: to scale, laid out from the 3D structure, with DNA, ligands, membranes and symmetry.

pip install "foldmap @ git+https://github.com/dzyla/foldmap.git"
foldmap plot 1LMB -o lambda.svg

How a diagram is made

Every figure, from the command line, the app or an AI agent, goes through the same eight steps.

  1. Read

    gemmi reads the file, or the one downloaded for a PDB ID or UniProt accession; biological assemblies are built from its operators.

  2. Secondary structure

    A DSSP implementation finds backbone hydrogen bonds and calls α- and 3₁₀ helices, strands with bulges, and turns.

  3. Sheets

    Strands joined by H-bond ladders form sheets; order and direction come from the ladders; closed barrels are recognised.

  4. Context

    Symmetry from chain superposition; disulfides, glycans and ligands from the atoms; the membrane estimated on request.

  5. Projection

    3D is turned into the page: dominant direction up, assemblies unrolled around their axis, DNA complexes around the DNA. Never mirrored.

  6. Layout

    One energy is minimised: springs to projected positions, short loops, contacts and disulfides pulling together, no overlaps.

  7. Loops

    Each loop is routed on a grid by A* search: orthogonal lines around elements and labels.

  8. Draw

    Elements to scale, then loops, annotations and legend; SVG keeps text as text for editing.

Steps 1–7 depend only on the structure, step 8 on the theme: restyling never moves anything.

Use it your way

Command line

foldmap summary 1UBQ
foldmap plot 1UBQ -o fig.svg --theme journal
foldmap plot P04637 -o p53.png --theme alphafold
foldmap sequence 1UBQ -o aln.svg --msa family.fasta
foldmap interactive 8UTF -o explorer.html

App

A Streamlit app: load a PDB ID or file, pick a style from previews of your structure, tune every option, download SVG, PNG, PDF and layout files.

pip install "foldmap[app] @ git+https://github.com/dzyla/foldmap.git"
foldmap app

AI agents (MCP)

An MCP server lets agents summarise structures and draw figures, with image previews.

claude mcp add foldmap -- foldmap mcp

Python

from foldmap.cli import make_figure
from foldmap.fetch import fetch
from foldmap.render import save

fig = make_figure(fetch("1UBQ"), title="Ubiquitin")
save(fig, "ubiquitin.pdf")
